# Current Theme Analysis - HuntSecrets (CipherChase)

## Current Theme: Neon Pink + Dark Cyberpunk
- Background: Dark image (transition.png) - Money Heist themed
- Primary accent: Pink/Magenta (#FF0080, #EC4899)
- Secondary accent: Green (#00FF80) for success states
- Text: White on dark translucent cards (bg-black/60 backdrop-blur-md)
- Borders: Pink-500 throughout
- Glows: Pink/Red neon shadows
- Font: Geist Sans + Geist Mono (Google Fonts)
- Style: Cyberpunk/Neon glow aesthetic

## Key Color Tokens Used:
- Pink: pink-400, pink-500, pink-600 (primary accent)
- Green: green-400, green-500 (success/correct)
- Red: red-400, red-500 (warnings/errors)
- Yellow: yellow-400 (penalty timer, gold rank)
- Gray: gray-200 to gray-900 (neutral elements)
- Background overlays: bg-black/60, bg-black/80
